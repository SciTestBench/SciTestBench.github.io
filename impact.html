Representative maintainer-confirmed findings

BiopythonConfirmed · fix unmerged

Codon adaptation must use synonymous-codon weights under the selected genetic code. Under table 4, TGG has weight 0.125, yet a query containing it receives CAI 1.0.

ObsPyConfirmed · fix unmerged

Normalized cross-correlation must not change under positive sensor gain. Doubling a nonzero waveform turns all-zero coefficients into nonzero ones.

NilearnConfirmed · fix unmerged

Changing the null baseline must update the signed z-score. A reused object returns +1.940, while a fresh object returns −0.988.

QuTiPConfirmed · fix merged

The self-fidelity of a normalized density matrix must equal one. A rank-2 mixture yields about 1+10−8; the fix reduces the error to float64 round-off.
