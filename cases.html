Failure Mechanisms

Most failures are tests that pass on the buggy code. The test runs, but its input never reaches the faulty behavior, or its oracle cannot detect it. The remaining failures reject the fixed code.

  • Mechanism mismatch (30.8% across both outcomes): the test exposes a real failure, but not the one the reference fix repairs.
  • Incorrect scientific premise (15.4%): the oracle encodes a physical equivalence or tolerance that does not hold.
  • Failure to expose the bug (53.8%): the input never reaches the critical regime.
